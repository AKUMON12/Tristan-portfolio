## 🌟 Key Features

1. **Cinematic Hero Experience:** Split-grid hero with an interactive floating syntax canvas (`< >`, `{ }`, `;`, `0101`, `=>`) featuring real-time mouse repulsion, paired with a glowing cyber-glass frame showcasing Tristan's official portrait.
2. **Infinite Marquee:** Continuous CSS-driven loop showcasing primary frameworks, tools, and platforms (Node.js, Next.js, PostgreSQL, Supabase, Cisco CCNAv7, Docker, Gemini AI).
3. **Deep Case Studies:** Comprehensive project showcase with live links, repositories, and a 4-pillar breakdown:
   - The Problem Solved
   - Role & Architectural Approach
   - Key Challenge & Solution
   - Quantifiable Outcome & Impact
4. **Interactive Resume Modal:** Live embedded PDF viewer with one-click direct download of Tristan's official resume (`Tristan_Elvinia_Resume.pdf`).
5. **Categorized Skills Matrix:** Visual metric bars breaking down Frontend & UI/UX, Backend & Databases, AI Engineering & IoT Prototyping, and DevOps/Networking.
6. **Cisco Certification Vault:** Accredited credentials for Cisco CCNAv7 (SRWE) and Cisco Introduction to Cybersecurity.
7. **Suspense & Akumon Labs:** Interactive terminal simulator with executable commands (`status`, `skills`, `projects`, `contact`, `labs`) plus a sneak peek into upcoming R&D innovations.
8. **Fully Responsive & Accessible:** Optimized for Desktop (1440p+), Tablet, and Mobile with dark/light mode toggle and zero viewport layout shifts.

## ⚙️ Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/AKUMON12/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### 4. Build for production
```bash
npm run build
npm run start
```
